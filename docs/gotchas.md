移植时对着看，比重新踩一遍便宜。

## tmux

### T-1
**`-F` 的分隔符不能用真控制字符。** 用 `US`(0x1f) 这类字符去拼字段，行为跟 tmux
版本有关——3.5a 会把它转义成字面的 `\037` 四个字符，3.7c 原样输出真字节。
两边都想切得开，就用可打印的 `␟`(U+241F)：tmux 原样透传，用户又几乎打不出来。

### T-2
**`pane_title` 必须放在最后一个字段。** 它是终端里的程序随便设的，可能混进任何
字符（包括你的分隔符）。放中间会把后面的字段挤错位，而且是偶发的。解析时用
`parts.slice(n).join(SEP)` 兜回来。

### T-3
**要 `window_activity`，不是 `session_activity`。** 后者只在会话被 attach 或
操作时才更新——pane 里刷屏刷到天亮它都不动。拿它做「有新输出」的角标，
后台跑着的活永远不会提示你。

### T-4
**`-t "=name"` 精确匹配不是所有命令都认。** `has-session`、`kill-session`、
`attach-session`、`list-panes`、`list-clients` 支持；`set-option`、`capture-pane`、
`display-message` 不支持，会报 `no such session` 或 `can't find pane`。
不支持的地方只能传裸名字，所以会话名要定长，避免前缀模糊匹配误伤。

### T-5
**「no server running」不是故障。** 一个会话都没有时 tmux 就这么报错，
按故障处理的话列表接口会直接抛。匹配 stderr 后返回空数组。

### T-6
**建会话和 attach 都要显式给尺寸。** 不给就按 80x24 排版，TUI 首屏全是错行。
`new-session -x/-y`，attach 时带上 cols/rows。

### T-7
**`window-size latest` 不设的话，tmux 取所有客户端里最小的尺寸**——手机一连上来，
桌面端就被挤成一条缝。

### T-8
**`window-size` 要设成全局。** 它是 window option，拿 session 名当 target 会被拒
（`no such window`）。socket 既然是独占的，`-g` 设一次反而更干净。

### T-9
**要开 `mouse on`。** 不开的话 attach 会让终端进 alternate screen，而浏览器里的
终端在 alt screen 里把滚轮转成方向键（本来是给 less/vim 用的），结果往上滚
翻出来的是 shell 的历史命令，不是上面的输出。代价见 T-14。

## 终端回放

### T-10
**attach 只重绘当前屏，不带历史。** 想让「关了页面回来还能往上翻」，得在 attach
之前先推一次 `capture-pane`。

### T-11
**capture 出来的行尾没有 `\r`。** 直接喂给 xterm 会阶梯状错位，要先
`replace(/\r?\n/g, "\r\n")`。

### T-12
**回放前要先 reset。** 不然旧内容和回放叠在一起，看起来像输出了两遍。

### T-13
**必须先量好尺寸再连。** 挂载那一帧容器还没有尺寸，终端仍是默认 80x24；用这个
尺寸 attach，tmux 会先按 80x24 画一屏，等尺寸校正后的 resize 到达再重画一次——
那次重绘会把刚回灌的历史整屏抹成空白。新建的会话尤其明显：连上去是一片空，
敲一下才冒出提示符。

### T-28
**但也不能只靠 `requestAnimationFrame`。** Chrome 在隐藏标签页里根本不跑 rAF。
只挂 rAF 的话，在后台标签页打开（⌘点开链接、或恢复上次会话时的非当前标签），
每个终端都停在 80x24 且从不建立连接，切回前台也不会自己好。
对策：rAF 和一个 ~120ms 的定时器同时挂，谁先到谁执行（只跑一次）；
再监听 `visibilitychange`，回到前台时补一次尺寸校正。

## 标题自动跟随

### T-17
**要剥掉标题开头的装饰字符。** 有些程序会在名字前挂 spinner 状态指示，那个字符
每几百毫秒换一个，不剥的话标签会一直抖，而且抖动会把「有没有变化」的判断带偏。

### T-18
**采信程序自报的标题时，只看标题本身有没有信息量，别看在跑什么命令。**
曾经的判据是「有非 shell 的程序占着终端才采信」，那是错的：Claude Code 这类
工具跑起来之后 `pane_current_command` 仍然是 `bash`（它不是前台进程组的领导），
于是真正的会话名被这条判据挡了个正着，标签一直显示目录名。

### T-19
**shell 自己设的标题要排除干净。** `user@host:path` 要排除，光一个路径、光一个
目录名要排除，**只有机器名也要排除**——有些 shell 就往标题里写一个 hostname，
不排除的话空闲 shell 会被命名成一长串机器名。

### T-20
**创建会话必须串行化。** 并发建的话每一路都读到同一份「已有会话」再去编号，
连按几下新建会出来一串重名的。

## 浏览器

### T-14
**文本选择会被鼠标事件抢走。** tmux 开了 `mouse on` 之后，普通拖拽被发给 tmux，
用户看起来就是「怎么拖都选不中」。对策是在捕获阶段把无修饰键的左键 mousedown
换成一份带「强制选择」修饰键的合成事件——Mac 上是 Option，其它平台是 Shift。

### T-15
**Mac 还要显式打开 `macOptionClickForcesSelection`。** 否则按帮助里写的 Shift
也选不中——Mac 的 xterm 只认 Option。

### T-16
**复制不能只靠 `navigator.clipboard.writeText`。** 自签 HTTPS、权限策略或浏览器
设置都可能让它拒绝，而把异常静默吞掉后还 `preventDefault`，用户看到的就是
「按了复制但什么也没有」。要走同步的 `copy` 事件 + 临时 textarea + `execCommand`，
最后才退到 Clipboard API。

### T-21
**标签的 mousedown 必须 `stopPropagation`。** 格子的 mousedown 会把焦点交给终端的
textarea，而 Chrome 在 mousedown 后焦点一动就取消拖拽——不拦的话标签根本拖不动。

### T-22
**双击重命名做不了。** 单击会重建侧栏，原元素当场销毁，第二下点在新元素上，
双击事件永远不触发。重命名走右键菜单和快捷键。

### T-23
**弹层期间要把终端的 stdin 整个关掉。** 光做「不抢焦点」防不住：任何让终端
textarea 重新拿到焦点的路径，都会让用户敲的字直接进 shell，而输入框里一个字
都没有。另外每秒一次的状态刷新也不能抢焦点，否则表现是「改完名字回车没反应」。

### T-24
**绝不用原生 `prompt`/`alert`。** 它们会阻塞页面，更要命的是全屏时弹出会让浏览器
退出全屏——按一次重命名就掉出键盘独占。

### T-25
**Keyboard Lock 要先 unlock 再 lock。** 已经注册过一个锁时直接再 lock 会抛
`InvalidStateError`，结果就是「看着进了独占，其实一个键都没锁住」——而这件事
用户是感觉不到的，直到按了 `⌘T` 发现开了个浏览器标签页。所以锁定结果要显示出来。

另外 **`Escape` 必须锁进去**：不锁的话它归浏览器管，全屏下按一下就退出独占，
而 Esc 在终端里是最高频的键之一。锁上之后退出全屏改成长按 Esc。
**`Ctrl+Shift+R` 是 Chrome 的强制刷新，拦不住**，非 Mac 的键位要避开它。

### T-29
**未读水位不能记浏览器时钟。** `activityAt` 来自 tmux 的 `window_activity`，是
服务端时钟；如果把「看到哪儿了」记成 `Date.now()`，就是在跨机器比较两个不同的
时钟：服务端快于浏览器 → 看过的会话切走就永久亮黄点；浏览器快于服务端 →
真有新输出也不亮。水位要存**那个会话自己的 `activityAt`**，全程只和服务端时钟比。

## 其它

### T-26
**令牌不能拦静态资源。** iframe 嵌入时 `SameSite=Lax` 的 cookie 不会随子资源
请求发送，拦静态会让嵌入页白屏——页面能开、`/assets/*` 全 401，这种形态
排查起来非常费劲。

### T-27
**`node-pty` 装完可能一 spawn 就抛 `posix_spawnp failed.`** 这不是 ABI 不匹配
（那会在 require 时就炸）。真因是打包解压丢掉了预编译 `spawn-helper` 的执行位，
`chmod +x` 就好。挂成 postinstall，否则每次重装都要再踩一次。

### 粘贴图片
**不要对目标目录 `mkdir`。** 它本来就存在，而 `mkdir` 打到 `/proc` 之类的特殊
路径上会挂很久（实测能卡 20 秒）。直接写，写不进去就退回一个兜底目录——用户
可能正 cd 在 `/usr` 之类地方，为这个把粘贴功能整个废掉不值当。

### 端口
**`0` 是合法值。** 它表示「让系统随便挑一个」，测试要靠它才能和正在跑的实例
并存。按「非正数即无效」去解析会把它退回默认端口，然后两边抢端口。
